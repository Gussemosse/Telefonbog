# Telefonbog

telefonbog.py er selve programmet, hvor den samlede telfonbog ligger. Selve programmet bruger python standard biblioteker, dermed burde de ikke være noget problem. Men denne fil skal køres, for at se programmet.

## pytest
Det er også muligt at afprøve valideringsprogrammet, med hjælp fra "pytest" biblioteket. Hvor der skal skrives "pytest" i terminalen, for at køre valideringen.
